# 庭ガレージ日照シミュレーター

任意のGPS座標・庭の寸法を入力し、庭に任意サイズの直方体(ガレージなど)を設置した場合に、
縁側(家の開口部)へ入る日光がどのように変化するかをシミュレーションするWebアプリです。

## 構成

- `backend/` — Python (FastAPI) 製のAPIサーバー
  - `app/solar_position.py` — Meeus/NOAAの太陽位置アルゴリズムによる太陽高度・方位角の計算(自前実装、外部依存なし)
  - `app/weather.py` — [Open-Meteo](https://open-meteo.com/) から実測/予報の日射量データ(全天日射・直達日射・散乱日射)を取得する外部データクライアント。取得できない場合は簡易晴天モデルにフォールバック
  - `app/shadow.py` — 庭のローカル座標系における、直方体(ガレージ)の影の当たり方をレイキャスト(スラブ法)で計算するジオメトリ
  - `app/simulation.py` — 上記を組み合わせて1日分のタイムラインを生成するオーケストレーション
  - `app/main.py` — FastAPIアプリ本体。`/api/simulate` でシミュレーションを実行し、`frontend/` を静的配信
  - `tests/` — pytestによるユニット/統合テスト
- `frontend/` — ビルド不要の素のHTML/CSS/JS。庭の平面図・影の動き・日照グラフを描画

## セットアップ・起動方法

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

ブラウザで `http://localhost:8000/` を開くと、フォームとAPIが同一オリジンで動作します。

## テスト

```bash
cd backend
source .venv/bin/activate
pip install pytest
python -m pytest
```

## モデルの前提・簡略化

- 庭はローカル座標系 (X: 家に対して左右方向, Y: 家から庭の奥へ向かう方向, Z: 上方向) の平坦な地面として扱います。
- 家自体は Y=0 の不透明な壁とみなし、縁側 (Y=0 上の複数サンプル点) は、太陽が「庭側」を向いているときのみ直射日光を受けられるとします。
- ガレージは1つの直方体(回転可能)として近似し、庭の任意位置に配置できます。
- 直射日光の有無はサンプル点から太陽への視線とガレージ直方体の交差判定(レイ/AABBのスラブ法)で判定し、縁側全体の「日照面積割合」を各時刻で算出します。
- 日射量(W/m²)はOpen-Meteoの実測/予報値(全天日射・直達日射・散乱日射)を使用し、直射成分に日照面積割合を乗じ、散乱成分はそのまま加算する簡易モデルで、ガレージ設置前後の有効日射量を比較します。
- タイムゾーンはOpen-Meteoが緯度経度から自動解決したUTCオフセットを使用します(外部APIが利用できない場合は経度から簡易推定)。
- 反射光・地面の起伏・隣接建物・樹木・雲の局所的な動きなどは考慮していません。実際の建築設計における日照検討の代替にはなりません。
